# Commit Guide

Use descriptive commits after each completed section. Do not commit everything with random messages.

Recommended flow:

1. Initialize Next.js summer ecommerce project
2. Configure Tailwind DaisyUI and global theme
3. Add summer product JSON data and local SVG assets
4. Build persistent navbar and footer layout
5. Create home hero sale banner and popular products
6. Add summer care tips and top brands sections
7. Create products listing and protected details routes
8. Configure BetterAuth API route and auth client
9. Build login and register pages with Google login button
10. Add protected profile page and update information form
11. Write README setup deployment and submission checklist
